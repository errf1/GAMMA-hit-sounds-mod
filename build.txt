Build the mod from the project root:

dotnet build .\GammaHitSounds.csproj -c Release `
  -p:RimWorldDir="D:\Games\Steam\steamapps\common\RimWorld" `
  -p:HarmonyDir="D:\Games\Steam\steamapps\workshop\content\294100\2009463077\Current\Assemblies"

RimWorldDir points to the game installation. HarmonyDir points to the directory containing 0Harmony.dll.
Alternatively, set the RIMWORLD_DIR and HARMONY_DIR environment variables.
Requires the .NET SDK and .NET Framework 4.7.2 Developer Pack.
Release output is written to GAMMA hit sounds\Assemblies.
